# CineDiary 🎬📖

CineDiary é uma **aplicação web para acompanhar filmes, séries e animes**, registrar o progresso, avaliar e comentar sobre cada conteúdo.  
O projeto é uma **Single Page Application (SPA)** feita em **React**.

---

## 🔹 Funcionalidades principais (MVP)

- Buscar filmes, séries e animes via API da [TMDB](https://www.themoviedb.org/)
- Adicionar conteúdo à biblioteca pessoal
- Marcar status do conteúdo:
  - Desejo assistir
  - Assistindo
  - Concluído
- Registrar progresso de episódios em séries/animes
- Avaliar e comentar sobre cada conteúdo
- Visualizar seções separadas: “Desejo”, “Assistindo”, “Concluído”
